# Swiper Blog Carousel for Squarespace (and beyond)

A free, responsive blog carousel built with **Swiper.js**, styled to match any brand, and deployable on nearly any CMS.

Originally designed for [my Squarespace site](https://www.geoffmosher.me), this code can be dropped into **Framer**, **WordPress**, **Webflow**, or any platform that allows HTML/CSS/JS injection.

No third-party plugins. No bloat. Just clean code and seamless integration.

---

## 🛠 What It Does

- Fetches the latest blog posts from any RSS feed (via `rss2json.com`)
- Displays them in a swipeable carousel with:
  - Thumbnail image
  - Title
  - Date
  - Excerpt
- Adds a final slide with a customizable CTA (e.g., “View More” or “Scroll on”)
- Fully responsive on mobile, tablet, and desktop

---

## 📋 How to Use It

1. **Copy the full code snippet** into your site’s HTML/code block
2. **Replace** the RSS feed URL with your own
3. **Customize** fonts, colors, and CTA to match your brand
4. **Save + refresh** your site to see it live

That’s it. No build tools or server dependencies needed.

---

## 🧠 Why This Approach?

- Most CMS tools limit native styling and layout control
- Paid widgets like Elfsight look generic or cost too much
- Swiper.js is lightweight, battle-tested, and customizable
- You can host and style everything yourself, for free

<script src="https://cdn.jsdelivr.net/npm/swiper@11/swiper-bundle.min.js"></script>
<script>
  fetch("https://api.rss2json.com/v1/api.json?rss_url=https://feeds.feedburner.com/your-blog-name/blog")
    .then((res) => res.json())
    .then((data) => {
      const container = document.getElementById("blog-carousel");
      data.items.slice(0, 5).forEach((post) => {
        const slide = document.createElement("div");
        slide.className = "swiper-slide";

        const thumbnail = post.thumbnail ||
          (post.enclosure ? post.enclosure.link : "https://via.placeholder.com/600x400?text=No+Image");

        slide.innerHTML = `
          <a href="${post.link}" style="text-decoration: none; color: inherit; display: flex; flex-direction: column; height: 100%;">
            <div class="blog-thumbnail-container">
              <img class="blog-thumbnail" src="${thumbnail}" alt="${post.title}" />
            </div>
            <div class="blog-content">
              <div class="blog-title">${post.title}</div>
              <div class="blog-date">${new Date(post.pubDate).toLocaleDateString()}</div>
              <div class="blog-excerpt">${post.description.substring(0, 120)}...</div>
            </div>
          </a>
        `;

        container.appendChild(slide);
      });

      const moreSlide = document.createElement("div");
      moreSlide.className = "swiper-slide view-more-slide";
      moreSlide.innerHTML = `<a href="/blog" class="view-more-button">View more</a>`;
      container.appendChild(moreSlide);

      new Swiper(".swiper-container", {
        slidesPerView: 1,
        spaceBetween: 20,
        navigation: {
          nextEl: ".swiper-button-next",
          prevEl: ".swiper-button-prev",
        },
        breakpoints: {
          640: {
            slidesPerView: 1,
          },
          768: {
            slidesPerView: 2,
          },
          1024: {
            slidesPerView: 2.8,
            centeredSlides: false,
          },
        },
      });
    });
</script>
