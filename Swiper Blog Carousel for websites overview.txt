# Swiper Blog Carousel for Squarespace (and beyond)

A free, responsive blog carousel built with **Swiper.js**, styled to match any brand, and deployable on nearly any CMS.

Originally designed for [my Squarespace site](https://www.geoffmosher.me), this code can be dropped into **Framer**, **WordPress**, **Webflow**, or any platform that allows HTML/CSS/JS injection.

No third-party plugins. No bloat. Just clean code and seamless integration.

---

## 🛠 What It Does

- Fetches the latest blog posts from any RSS feed (via `rss2json.com`)
- Displays them in a swipeable carousel with:
  - Thumbnail image
  - Title
  - Date
  - Excerpt
- Adds a final slide with a customizable CTA (e.g., “View More” or “Scroll on”)
- Fully responsive on mobile, tablet, and desktop

---

## 📋 How to Use It

1. **Copy the full code snippet** into your site’s HTML/code block
2. **Replace** the RSS feed URL with your own
3. **Customize** fonts, colors, and CTA to match your brand
4. **Save + refresh** your site to see it live

That’s it. No build tools or server dependencies needed.

---

## 🧠 Why This Approach?

- Most CMS tools limit native styling and layout control
- Paid widgets like Elfsight look generic or cost too much
- Swiper.js is lightweight, battle-tested, and customizable
- You can host and style everything yourself, for free

---

## ✅ Benefits
